## Confirm that the unit exists

Find the authored unit in **Showroom** using its identifier. If it is unresolved or broken, inspect that source problem first.

## Follow the eligibility chain

| Relationship | Check |
| --- | --- |
| Nationality or allegiance | The unit belongs to the intended side and country |
| Coalition | The country is a valid member |
| Specialization | The unit's relevant type membership fits the selection |
| Era | The production year fits the actual category ceiling |
| Combination | The nation, specialization, and era are permitted together |
| Roster or deck membership | The authored unit belongs to the source roster required by the task |
| Selector and code | The deck type is listed and has the intended encoding assignment |

## Check what the game loaded

Save, repack, and confirm the intended installed mod is enabled. Use the same nation, specialization, era, and unit identity in your comparison.

If the game still shows an older version, inspect output status and the destination before changing source again.
