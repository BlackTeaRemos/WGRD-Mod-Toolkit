description: "Check source availability, the active mod, and pending operations."
---

## Inspect these in order

1. **Workspace preparation:** did the required data finish preparing?
2. **Active mod:** is an editable workspace mod selected?
3. **Owner:** have you selected the unit, weapon, or deck entry that uses the control?
4. **Pending work:** is an operation still saving, loading, or importing?
5. **Draft context:** does the draft belong to the current owner and workspace session?
6. **Diagnostic:** has the application explained why the operation is unavailable?
