Open the gear button in the top bar for **Settings**.

See [Toolkit appearance and language](/WGRD-Mod-Toolkit/parameters/text-settings/#toolkit-appearance-and-language) for local preferences. Game interface settings are covered in [interface parameters](/WGRD-Mod-Toolkit/parameters/interface/).

## Controls

1. Use **Appearance** to choose Dark, Light, Mod Manager, or Mod Manager Light.
2. Use **Interface language** to choose an available translation or return to English.
3. Use **Third-party libraries** to read library credits and licenses.

Appearance and language changes apply immediately and are remembered for the next session. Control names in this manual use English.

Use [Workspace controls](/WGRD-Mod-Toolkit/start/controls/) to change the selected workspace or mod.
