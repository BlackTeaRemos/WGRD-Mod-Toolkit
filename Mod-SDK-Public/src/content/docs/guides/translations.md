---
title: "Names and translations"
description: "Edit displayed names, identifiers, and language rows."
---

Use **Translations** in Showroom, Weapons, or Decks to edit displayed text.

For individual fields, see [translation parameters](/WGRD-Mod-Toolkit/parameters/text-settings/#translation-fields-and-ownership).

## Name controls

| Name | Control |
| --- | --- |
| Unit or weapon display name | Its **Translations** inspector |
| Cloned unit identifier | **General name** |
| Specialization or era name | Its Decks **Translations** section |
| Country or coalition name | The entry's translations |
| Emoji tag | The tag editor |

Translating a display name leaves its identifier unchanged. Only cloned units can have their stable name changed.

## Language rows

Select the entry, open **Translations**, choose a language, and edit its text.

Some entries have separate menu and in-game text. Choose the row for the place you want to change.
