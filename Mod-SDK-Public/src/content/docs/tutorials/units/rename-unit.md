---
title: "Rename a unit"
description: "Change a displayed name or cloned unit identifier."
---

A unit can have an identifier such as `Training_Tank` and a displayed name such as `Training Tank`.

## Displayed name

1. Select the unit and open **Translations**.
2. Choose the language and text row.
3. Edit and save the wording.
4. Repack and check it in that game language.

Some entries have separate menu and in-game text.

## Identifier

1. Select an editable cloned unit and finish pending edits.
2. Enter an available identifier in **General name**.
3. Save and let the source refresh.
4. Find the unit by its new identifier and check related entries.

The rename control updates supported authored references.
