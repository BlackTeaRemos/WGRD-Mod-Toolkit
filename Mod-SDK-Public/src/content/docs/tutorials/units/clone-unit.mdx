Select an editable mod and a source unit with the role and movement type you need.

## Steps

1. Find the unit in **Showroom** and select it.
2. Use **Clone**, enter a new identifier, and confirm.
3. Wait for saving, then select the clone.
4. Use **Translations** to change its displayed name or **Stats** to change gameplay.
5. Review its country, production year, deck membership, and weapons.
6. Repack and find it in the intended game deck.
