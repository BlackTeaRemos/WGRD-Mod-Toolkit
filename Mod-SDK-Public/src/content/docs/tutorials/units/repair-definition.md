---
title: "Repair a broken definition"
description: "Fix a missing reference or asset."
---

## Steps

1. Find the broken unit or weapon in **Showroom** or **Weapons**.
2. Select it and read the field, reference path, and missing target in its diagnostic.
3. Find the intended target in the relevant catalogue.
4. Use the owning inspector control to choose a compatible target, or restore the missing asset.
5. Save, reopen the entry, and check the same diagnostic.
6. Resolve required references before repacking.

If you cannot identify the intended target, report the problem with its diagnostic.
