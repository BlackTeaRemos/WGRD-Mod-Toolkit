Select an editable mod and find the unit in **Showroom**.

## Steps

1. In **Stats**, check the unit's country, specialization membership, and production year.
2. Change the values needed for the intended deck.
3. In **Decks**, select the specialization or era and check **Listed in deck selector**, **Combinations**, and its **Deck-code slot**.
4. For a coalition, check **Members**. For a country, check that the correct side offers it.
5. Repack and select the same country, specialization, and era in game.
