---
title: "Change a gameplay value"
description: "Edit a unit's stats."
---

## Steps

1. Select the unit in **Showroom** and open **Stats**.
2. Find the field and note its current value.
3. Enter the new value using the units shown by the control.
4. Finish the input and wait for saving.
5. Return to the unit to check the value.
6. Repack and compare the unit in game.

Keep the same veterancy, deck bonuses, terrain, and target when comparing results.
