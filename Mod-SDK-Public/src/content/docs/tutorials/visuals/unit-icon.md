---
title: "Replace a unit's icon"
description: "Import a catalogue image for a unit."
---

Create a unit variant first if the new icon should belong to a separate unit.

## Steps

1. Select the unit in **Showroom** and find its image controls.
2. Export the current image if you need a reference.
3. Use the import or replacement action and choose a supported image.
4. Check framing, orientation, and transparency.
5. Select another entry, then return to check the saved icon.
6. Repack and inspect the icon in game.
