---
title: "Export a model"
description: "Export an FBX for an external editor."
---

## Steps

1. Select the unit in **Showroom** and choose the model or LOD.
2. Choose the mesh, rigged, or scene FBX export that suits your task.
3. Save the file and open it in your model editor.
4. Check its orientation, scale, and expected parts against the Toolkit preview.

## Import an edited model

Use the selected unit's model import control. Then inspect its materials, rig, and attachments before repacking.
