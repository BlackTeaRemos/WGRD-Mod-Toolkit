---
title: "Keep history for an editable mod"
description: "Commit, sync, and push a mod with Git."
---

Install system Git and finish pending mod saves.

## Commit changes

1. Select the mod and open **Git**.
2. Use **Create Git repository** if it has no repository.
3. Review the changed files.
4. Use **Commit** to save them on the mod's commit branch.

## Sync and push

Set **Origin** to an existing repository and use **Save origin**.

- **Sync** fast-forwards from the remote default branch. Resolve divergent histories with Git.
- **Push** sends the commit branch to Origin.

Authentication uses your system Git setup. Install Git LFS if the project needs it.
