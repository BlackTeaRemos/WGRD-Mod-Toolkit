---
title: "Prepare a mod release"
description: "Build and share a finished mod."
---

## Steps

1. Select the mod in **Workspace** and finish pending saves.
2. Check that changed entries and imported assets are available.
3. Record the Toolkit version and source revision.
4. Use **Repack** and read the operation report.
5. Enable the mod in game and try its main changes.
6. Distribute the generated output with the mod version, game requirements, and known issues.

Retain the Toolkit attribution required by its shipped license.
