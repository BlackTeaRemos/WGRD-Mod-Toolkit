---
title: "Move an editable project"
description: "Transfer a mod's source and assets."
---

## Steps

1. Finish saving the mod.
2. Transfer its editable source together with images, models, translations, and other referenced assets.
3. Include the Toolkit version, required game data, and instructions for any external inputs.
4. Prepare a workspace on the receiving machine and open or import the transferred source.
5. Select the mod and check a unit, an image or model, and a deck entry.
6. Repack from the transferred source.

Generated packs alone are not an editable project.
