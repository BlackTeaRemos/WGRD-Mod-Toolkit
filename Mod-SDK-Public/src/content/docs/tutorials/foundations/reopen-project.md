---
title: "Confirm an edit survives reopening"
description: "Check that an edit was saved."
---

## Steps

1. Select an authored unit, weapon, or deck entry and note its identifier.
2. Edit a value and finish any **Apply** or **Save** action.
3. Wait for saving to complete.
4. Select another entry, then return and check the value.
5. Reopen the mod or application and find the same identifier again.

| Problem | Action |
| --- | --- |
| Value saved, preview missing | Read the preview's asset or reference diagnostic. |
| Source changed, game unchanged | [Repack](/WGRD-Mod-Toolkit/start/controls/) and enable the correct output. |
