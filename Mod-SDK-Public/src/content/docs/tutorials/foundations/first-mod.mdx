Use [Workspace controls](/WGRD-Mod-Toolkit/start/controls/) to prepare a workspace and select an editable mod.

## Steps

1. Open **Showroom** and select a familiar unit.
2. Use **Clone** and give the copy a name such as `Training_Tank`.
3. Open the clone's **Translations** and set its displayed name to `Training Tank`.
4. Finish the edit and wait for saving to complete.
5. Select another unit, then return to the clone to check its name.
6. Use **Repack**, enable the mod in game, and find the new unit.
