## Steps

1. In **Decks**, select a coalition or create one with an available tag.
2. In **General**, set its selector visibility.
3. In **Members**, choose a side and at least one country. Remove countries from the other side.
4. In **Combinations**, set the allowed specializations and eras.
5. Use **Translations** for the displayed name.
6. In **Flags**, import artwork for **Normal flag** and **Long flag** where available.
7. Repack and select a permitted coalition deck in game.
