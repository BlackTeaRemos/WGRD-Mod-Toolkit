---
title: "Create an emoji tag"
description: "Import a tagged image and set its rendering."
---

Tags accept letters, digits, and underscores. For example, `TrainingBadge` is shown as `#TrainingBadge`.

## Steps

1. Select an editable mod and open **Decks**' emoji section.
2. Enter an unused name in **New emoji tag**.
3. Use the add button or confirm the field.
4. Choose the image, then select the new tag in the list.
5. Set **Mirror horizontally** and **Tint with text color**.
6. Repack and use the tag in a text location that supports formatted image tags.
