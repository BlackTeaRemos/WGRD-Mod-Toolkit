Prepare an image in a format offered by the picker. Export an existing picture if you need its size or transparency as a reference.

## Steps

1. In **Decks**, select the specialization or era.
2. Open **Appearance**.
3. Use **Import**, or click the existing image to replace it.
4. Choose the file and inspect its preview.
5. Reopen the entry, then repack.

<InterfaceCapture image={bonusImagePreview} alt="Armored Appearance section showing its Bonus image preview and Remove image control." caption="Bonus image preview." />

- **Revert** restores the baseline assignment, or no image for a new type without one.
- **Remove image** clears the assignment.
