## Steps

1. In **Decks**, create or clone an era category and give it a name.
2. Open **General** and set **Production-year limit**.
3. Use **Translations** for its menu name.
4. Set **Listed in deck selector** and assign a **Deck-code slot**.
5. Set **Combinations** and any desired bonuses.
6. Repack and compare units with production years before and after the limit.
7. Save or read a deck code using the category.

<InterfaceCapture image={eraGeneral} alt="Before 1985 category selected with Production-year limit 1985 in General." caption="Era year limit and deck-code slot." />

The unrestricted category ignores its year limit and bonuses.
