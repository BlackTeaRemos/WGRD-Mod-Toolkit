## Steps

1. In **Decks**, select a specialization and use **Clone**, or create a new named type.
2. In **General**, set **Listed in deck selector** and its **Deck-code slot**.
3. Edit activation points or a bonus in **Costs**, **Slots**, **Veterancy**, or **Unit availability**.
4. Use **Translations** for the menu name.
5. In **Appearance**, import the specialization's picture.
6. Set the allowed countries, coalitions, and eras in **Combinations**.
7. Repack and try the specialization and its deck code in game.

<InterfaceCapture image={specializationGeneral} alt="Deck types catalogue with Armored selected and its General controls." caption="Specialization settings." />

The unrestricted specialization ignores its bonuses. Reassigning an occupied deck-code slot changes the meaning of existing codes that use it.
