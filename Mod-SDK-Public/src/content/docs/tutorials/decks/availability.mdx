## Steps

1. In **Decks**, select the country, coalition, specialization, or era.
2. Open **Combinations** and set the required specialization and era pairs.
3. In **General**, check selector visibility and deck-code registration.
4. Open **Unit availability** and edit the bonus for the intended category.
5. Finish saving, repack, and select that deck in game.
6. Compare availability using the same unit, veterancy, and transport.
