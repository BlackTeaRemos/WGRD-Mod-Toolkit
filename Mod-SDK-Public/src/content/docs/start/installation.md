## Prerequisites

- Windows.
- Wargame: Red Dragon installed so the Toolkit can prepare its game data.
- A writable workspace location with more than 100 GB of free space for prepared data, authored assets, and output. Keep it separate from the game's installation directory.
- WRG-Patcher installed to run mods in the game. We recommend [WGRD Mod Manager](https://github.com/BlackTeaRemos/WGRD-Mod-Manager), which installs the patcher for you.
- The Toolkit from the project's [releases](https://github.com/BlackTeaRemos/WGRD-Mod-Toolkit/releases). Follow the extraction or installation instructions supplied with the release.

## Creating workspace

1. Place or install the application in its own folder.
2. Launch the Toolkit and open **Workspace**.
3. Select the game installation and the location that will hold your workspace.
4. Start the workspace preparation offered by the application.
5. Wait for the operation report to confirm that workspace preparation is complete.
6. Select or create an editable mod in the workspace.

## Checkpoint

Congratulations, at this point, and after quiet a wait, you are now ready to work on modding.
