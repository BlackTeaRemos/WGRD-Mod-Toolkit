## Workflow

1. Open a prepared workspace and select an editable mod
2. Find the unit, weapon, or deck entry that owns the change
3. Edit the supported controls
4. Check the preview and let pending source writes finish
5. Use **Repack** to generate the current mod output
6. Check the result in the game

## Your first milestone

Follow [Create a first mod](/WGRD-Mod-Toolkit/tutorials/foundations/first-mod/). Its goal is a small, recognizable change that will make your first mod functional.

Each tutorial has an outcome and a checkpoint before the next stage.
