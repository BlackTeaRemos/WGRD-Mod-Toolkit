## Translation fields and ownership

| Control | Effect |
| --- | --- |
| Language text | Changes displayed wording in that language |
| Pin | Keeps the row independent from automatic related-language updates |
| Unpin | Allows those updates again |
| Withdraw | Removes the authored translation and uses the available fallback |
