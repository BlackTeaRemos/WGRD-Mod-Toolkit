# WGRD Mod Toolkit

Heavy SDK for Wargame Red Dragon mod creation through unified and rapidly working interface.

# Issues, Suggestions, Contact

## Your mods are yours

You own everything you make with WGRD Mod Toolkit - use it, share it, sell it, no royalty
owed. The one and only condition: leave the "Created with WGRD Mod Toolkit by BlackTeaRemos
(https://github.com/BlackTeaRemos)" attribution the tool writes into each mod.

## Downloads

Release builds are under [Releases](../../releases); the app self-updates from
there.

## Documentation

Public documentation lives in [`Mod-SDK-Public`](Mod-SDK-Public) and is published
to [blacktearemos.github.io/WGRD-Mod-Toolkit](https://blacktearemos.github.io/WGRD-Mod-Toolkit/).

The documentation covers installation, workspace authoring, Arsenal and campaign
workflows, WSD and public file references, tutorials, and troubleshooting.
